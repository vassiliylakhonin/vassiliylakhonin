# Vassiliy Lakhonin

I build tools to check AI answers against supplied sources, scope what agents may do, and prepare trade evidence for human review.

## Start here

**[See a citation check](https://output-verification.agendamcp.dpdns.org/#one-claim-review)**

A fictional report quotes “five warehouses.” Its source says “three warehouses.” The saved example shows the mismatched quote and a missing reference, then shows what remains for a human reviewer after a correction. Viewing the example uses no trial attempt.
